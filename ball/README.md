# 바운드볼 게임

React와 TypeScript로 만든 바운드볼 게임입니다. 원하는 이미지를 업로드하면 그 이미지로 공을 만들어 바운스하는 게임을 즐길 수 있습니다.

## 기능

- 이미지 업로드로 커스텀 공 만들기
- 물리 기반 바운스 애니메이션
- 중력, 마찰, 반발력 시뮬레이션
- 시작/정지/리셋 컨트롤

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 사용 방법

1. "이미지 선택" 버튼을 클릭하여 원하는 이미지를 업로드합니다.
2. "시작" 버튼을 클릭하여 게임을 시작합니다.
3. 공이 화면에서 바운스하며 움직입니다.
4. "정지" 버튼으로 게임을 멈추거나 "리셋" 버튼으로 공을 중앙으로 되돌릴 수 있습니다.
